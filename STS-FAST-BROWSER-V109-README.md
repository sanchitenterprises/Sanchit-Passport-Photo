Adds in-viewer Select option after Replace: drag over text then adjust either endpoint handle; selected existing PDF text is offered for a single Apply, with Undo/Redo and safe preview. Native PDF text replacement uses original font when the whole selected fragment is natively editable; otherwise refuses rather than layering mismatched text. Scanned PDF OCR selection uses both offline recognition engines; overlapping stamps, table lines and complex backgrounds block unsafe edits. Locked base v1.0.105 and working v1.0.108 are not modified. No private signing key is uploaded to public GitHub. On-phone PDF behavior has not yet been validated.
